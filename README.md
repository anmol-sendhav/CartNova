# 🛒 CartNova

**CartNova** is a modern, full-stack e-commerce application built with Java, Spring Boot, React and Microservices architecture. It aims to deliver a smooth shopping experience with secure authentication, product discovery, cart management, online payments and order tracking.

## 🚀 Project Overview

CartNova is designed to simulate a real-world e-commerce platform where customers can browse products, manage their shopping carts, place orders, make online payments and track deliveries.

The backend is designed using a microservices architecture to separate business responsibilities, improve maintainability and enable independent development of services.

## 🏗️ Planned Microservices Architecture

| Service | Responsibility |
|---|---|
| API Gateway | Routing and entry point |
| Auth Service | Authentication and authorization |
| Product Service | Product and category management |
| Cart Service | Shopping cart management |
| Order Service | Order processing |
| Payment Service | Payment integration and verification |
| Inventory Service | Stock management |
| Delivery Service | Address and delivery tracking |
| Review Service | Product reviews |
| Notification Service | Customer notifications |

### Infrastructure Services
- Eureka Server – Service discovery
- Config Server – Centralized configuration
- RabbitMQ – Asynchronous communication between services
